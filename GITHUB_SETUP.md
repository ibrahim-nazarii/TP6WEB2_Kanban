# GitHub Setup — Step by Step

Run these commands **one by one** in your terminal, from the project folder.

---

## 1. Open the project folder in terminal

```bash
cd /Users/er0sv/Documents/TP6_WEB
```

---

## 2. Initialize a Git repository

```bash
git init
```

---

## 3. Add all project files to staging

```bash
git add .
```

---

## 4. Make your first commit

```bash
git commit -m "Initial commit - demo site"
```

---

## 5. Rename the default branch to main

```bash
git branch -M main
```

---

## 6. Link your local repo to GitHub

```bash
git remote add origin git@github.com:ibrahim-nazarii/TP6WEB2_DemoProject.git
```

---

## 7. Push to GitHub

```bash
git push -u origin main
```

---

After the last command, your files will be live on:  
**https://github.com/ibrahim-nazarii/TP6WEB2_DemoProject**
